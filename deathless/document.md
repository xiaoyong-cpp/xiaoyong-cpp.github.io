# Deathless — 游戏设计文档

> 状态：已实现（背景板 + 日循环玩法）
> 最近更新：2026-11-01

---

## 0. 概述

极地极夜中的四十天。玩家是一只没有任何特殊身份的普通狼，以第一人称视角面对自然：没有名字的寓言，也没有"成为领袖"的成长线。活到第四十天日出即通关；生命值归零即死亡。

游戏是**纯背景板 + 第一人称文字**：画面里永远不出现狼，玩家与狼群都以缺席的方式存在。所有压力、身份、情绪都由光照、雾、星与文字承担。

---

## 1. 世界观与基调

- 玩家属于斯匹次卑尔根狼群（Spitsbergen Pack）——一个因在极寒极夜中全体生还、穿越斯匹次卑尔根岛而得名的狼群。
- 玩家在群中地位极低，属于最普通的那一类。这一点**不作为剧情主题展开**，只作为视角条件：看得少、离得远、排在最后。
- 基调：克制、低对比、无英雄特写、无煽情。死亡不画插画，日出不配音乐高潮。
- 极夜中没有昼夜明暗差，时间只能从维纳斯带与星的位置读出来。

## 2. 美术设计

### 2.1 画面构成（纯背景板）

分层（由远及近），全部为剪影与雾：

| 层 | 内容 | 视差深度 |
|---|---|---|
| 天空 | 竖向渐变 + 维纳斯带 + 地平线暖光 | 固定（无穷远） |
| 星空 | 上密下疏、独立呼吸闪烁 | 固定（无穷远） |
| 云 | 少量暗紫粉色柔边云 | 22–32 |
| 山脉 | 三层程序化山脊，越近越深 | 34 / 54 / 80 |
| 谷雾 | 夹在山脊层之间的漂移雾 | 40–88 |
| 松林 | 六层基准深度 + 每棵树独立 z 抖动，剪影摆动 | 70–152 |
| 地面 | 不透明实体色块，轻微受光 | 150 |

规则：

- 画面中**不出现任何狼**（玩家与狼群均不出场），避免生物造型带来的不适感。
- 不引入贴图、3D 模型、高光细节；所有元素共用一套色温。
- 不出现"重要事件发生了"的运镜、特写、镜头推进。

### 2.2 视差即身体

第一人称下，视差不是"看图"，是"看"本身：

- 静止：纵向呼吸 ±3px、0.16Hz，雾密度随呼吸微涨落
- 转头：水平位移 = 扫视；垂直 = 抬头/低头，地面占比随之变化
- 靠近/退让：整体视差幅度放大或收小，山与树的相对关系被拉开或压紧
- 无 HUD、无身体、无手、无脚步

### 2.3 日循环（四个时段）

每天四个时段，每个时段一次决策，光照只做微幅位移：

| 时段 | 天空 | 星 | 雾 | 用途 |
|---|---|---|---|---|
| 白天（极夜正午） | 冷蓝灰，能见度最好 | 约 30%，几乎不闪 | 偏薄 | 产出 |
| 傍晚（暮色） | 紫蓝回升 | 回升至 70% | 渐起 | 回气 |
| 凌晨（黎明前） | 紫调 +3%，维纳斯带最强 | 渐隐至 60% | 略薄 | 冒险/恢复 |
| 夜晚（深夜） | 基准深蓝黑 | 满，闪烁最活跃 | 中 | 恢复/关系 |

### 2.4 四十天光照弧线

两条时间轴叠加：日内四时段 × 全程四十天。只驱动同一组参数（天空色标、星密度与闪烁频率、雾厚、维纳斯带强度、地面受光量），不新增图层。

| 天 | 节点 | 光的语言 |
|---|---|---|
| 1 | 极夜开始 | 最后一次日落收尾，维纳斯带消失，星满天，风起 |
| 2–9 | 维持 | 基准画面，带极弱，星最活跃 |
| 10 | 寒潮来袭 | 空气变清、雾变薄、星不再闪、山看得更远但更冷硬 |
| 11–19 | 消耗 | 星缓慢减少，雾重新积起 |
| 20–25 | 暴风雪 | 画面灰白、横向飞雪粒子、狂风、树摇加剧；25 天恢复正常 |
| 23 | 迷失 | 树影重复、地面占比放大、视差幅度减小，方向感被剥夺 |
| 30 | 负伤 | 暗角加重、呼吸变慢变重、视野一侧被雾侵蚀，维纳斯带极弱回现 |
| 31–39 | 熬 | 维纳斯带每夜增强一点，星一颗颗回来 |
| 40 | 日出 | 唯一一次真正的亮度跃升：金粉地平线，星消失，地面第一次被照亮 |

### 2.5 字体与文字

- 正文：中文衬线 `"Noto Serif SC", "Source Han Serif SC", "Songti SC", "SimSun", serif`
- 字号 16px 起（Windows 回退宋体低于 16px 会发虚），行距 2.0，字距 0.08em
- 颜色 `#cfc6dd` @ 0.85，不用纯白；不描边、不投影、不加底板
- 标题：中文宋体 + 拉丁小型大写宽字距（如 `SPITSBERGEN`）
- 出场：整句 2–3 秒极慢淡入，句间留白 ≥ 1 秒；不用打字机音效
- 文字落在雾与地平线上，不遮挡地面细节

### 2.6 参数微刻度

右下角四条极细竖线（约 40px 高、1px 宽、`#cfc6dd` @ 0.5），从下往上填充：

- 不显示数字、名称、边框、底板
- 只在数值变化时，对应线条做 0.4 秒极缓明暗过渡；平时完全静止
- 阈值不报警、不变色，而是让线条**断开一截**（理智 < 2、羁绊 < 2 时中间出现缺口）
- 生命值单独置于最左，略高
- **第一次出现时机：第 1 天结算时**（此前画面只有光与雾）

## 3. 玩法结构

### 3.1 时间与结算

- 一天 = 四个时段，每时段一次决策，共 4 次/天；全程 40 天 = 160 次决策
- 结算顺序固定：**本时段选择 → 当日四次决策结束 → 衰减 → 阈值判定 → 惩罚 → 次日**
- 第 1 天无教学、无特殊事件，照常结算衰减

### 3.2 参数

四项，初始值与上限均为 **8**：

| 参数 | 含义 | 归零/低位后果 |
|---|---|---|
| 食物 | 体力来源 | 归零后每天扣生命 |
| 理智 | 清醒程度 | < 2 触发"神经透支" |
| 羁绊 | 与其他狼的关系 | < 2 自动触发"自相残杀" |
| 生命 | 最终判定 | 归零立即死亡 |

### 3.3 每日衰减

三项资源每天固定衰减，生命不自然衰减：

| 天数 | 每日衰减 |
|---|---|
| 1–10 | −2 |
| 11–20 | −3 |
| 21–30 | −4 |
| 31–40 | −5 |

第 10 天用正常剧情引导说明"递减幅度加大了"。第 31–40 天的衰减（5/8 ≈ 62.5%）超过上限的一半，最后十天**必须主动放弃一项资源**。

### 3.4 动作表

每个时段只从自己的菜单中选 1 项。

| 时段 | 选项 | 效果 |
|---|---|---|
| 白天 | 单独猎食 | 食物 +4 |
| | 集体猎食 | 食物 +2、羁绊 +2 |
| | 偷懒打盹 | 理智 +3 |
| | 舔舐伤口 | 生命 +1（生命满 → 散步，无效果） |
| 傍晚 | 单独猎食 | 食物 +3（能见度差，比白天少 1） |
| | 集体猎食 | 食物 +2、羁绊 +2 |
| | 偷懒打盹 | 理智 +3 |
| | 舔舐伤口 | 生命 +1（生命满 → 散步，无效果） |
| 凌晨 | 起早捕猎 | 食物 +3、理智 −1 |
| | 继续睡觉 | 理智 +2 |
| 夜晚 | 睡觉 | 理智 +4 |
| | 放哨 | 羁绊 +4 |

设计原则：单动作总价值约 4 点；单目标动作给满（+4），双目标动作拆分（2+2，易被上限吃掉溢出）。傍晚只削弱猎食、不削弱休息——白天产出、傍晚回气。

### 3.5 阈值与惩罚

| 状态 | 触发条件 | 后果 |
|---|---|---|
| 饥饿 | 食物 = 0 | 每天结算 −1 生命（可累积） |
| 神经透支 | 理智 < 2 | 每天 −1 生命；星闪紊乱、呼吸变浅、雾中多一层影子雾；决策菜单偶尔多出一行灰色"幻觉选项"，选中只掉理智 |
| 自相残杀 | 羁绊 < 2 | 一次性 −2 生命，羁绊强制回到 4，冷却 3 天（避免死亡螺旋） |
| 死亡 | 生命 = 0 | 视线下沉贴地 → 黑屏 → 一行宋体短句，无死亡插画 |

### 3.6 结局

- 第 40 天存活 → 日出，唯一的通关画面
- 中途生命归零 → 死亡
- 不做"完整/残缺"多结局分支

## 4. 剧情节点

### 4.1 节点表

| 天 | 内容 | 类型 |
|---|---|---|
| 1 | 极夜开始，日落收尾 | 引导（无特殊效果） |
| 10 | 寒潮来袭，说明递减加大 | 引导（无数值变化） |
| 20 | 暴风雪开始 | 表现层 |
| 23 | 迷失：跟丢狼群 | 机制 + 表现 |
| 25 | 风雪停止（若仍失群，迷失状态继续） | 表现层 |
| 30 | 负伤：生命立即 −3，夜晚选项永久改写 | 机制 |
| 40 | 日出 | 结局 |

节点日只替换**其中一个时段**的菜单，其余时段照常。当前设计为：23 与 30 的改写落到具体时段菜单（见下）。

### 4.2 第 23 天：迷失

- **触发条件**：剧情固定触发（与暴风雪同源——在风雪中跟丢狼群）
- **持续**：直到找到狼群；最早第 23 天，最晚第 29 天强制归队（防死锁）
- **期间菜单**：
  - 白天：单独猎食 / 偷懒打盹 / 舔舐伤口 / **寻找狼群**
  - 傍晚：单独猎食 / 偷懒打盹 / 舔舐伤口（集体猎食撤销）
  - 凌晨：起早捕猎 / 继续睡觉（不变）
  - 夜晚：睡觉 / **守夜**（原"放哨"改写，无羁绊收益，保证当晚安全）
- **寻找狼群**：基础成功率 35%，每次失败 +10%；第 29 天仍未找到则强制归队。归队当日的剩余时段恢复正常菜单
- **夜间遇袭**：迷失期间若夜晚选"睡觉"（不守夜），45% 概率遇袭：生命 −2、食物 −2
- **羁绊冻结**：迷失期间羁绊不衰减、不显示断口、不会触发自相残杀；归队后恢复正常
- **表现**：树影重复、地面占比放大、视差幅度减小、暗角加重；第 23–25 天叠加暴风雪

### 4.3 第 30 天：负伤

- 当日立即 −3 生命
- 夜晚"睡觉"**永久**替换为"舔舐伤口"：生命 +2、理智 +1（相比睡觉的 +4 理智明显变少）
- 生命满值时，夜晚该项替换为"睡觉（理智 +2）"，避免无效选项
- 表现：暗角加重、呼吸变慢变重、视野一侧被雾侵蚀
- 文案上需一句过渡（"刚回到队伍，就又倒下了"），避免玩家误认为数值错误

### 4.4 第 20–25 天：暴风雪

纯表现层，不改任何数值：

- 天空转灰白、降低饱和
- 横向飞雪粒子（水平方向为主，速度快、密度高）
- 风幅加大，松树摆动角度放大
- 第 25 天恢复正常

## 5. 数值可行性（设计验证）

| 阶段 | 每日需求（3 项） | 4 次动作可得 | 体感 |
|---|---|---|---|
| 1–10（−2） | 6 | 12–14 | 富余，惩罚代替教学 |
| 11–20（−3） | 9 | 12 左右 | 需要排布 |
| 21–30（−4） | 12 | 12–14 | 每步都要对 |
| 31–40（−5） | 15 | 13–16，但分不到三项上 | 必须放弃一项 |

最后十天参考路线（放弃理智、守住食物与羁绊）：

> 白天 集体猎食（+2/+2）、傍晚 集体猎食（+2/+2）、凌晨 起早捕猎（+3/−1）、夜晚 舔舐伤口（+2 生命/+1 理智）
> → 食物 +7、羁绊 +4、理智 0；理智崩至 0 触发透支（−1 生命/天），被夜间舔舐的 +2 生命抵消；羁绊约每 6 天跌破一次，触发一次 −2 生命。

该路线可活到第 40 天，但生命常年在 3–5 之间，任何一次贪心都会死。

调试用 URL 参数：`?day=N` 直接从第 N 天起跳（1–40），`?fast=1` 加速文字节奏以便验证。

| 状态 | 参数 | 变化 |
|---|---|---|
| 时段切换 | 天空色标位置 / 星 alpha / 雾 alpha / 山脊描边亮度 | 微幅位移，无图层变化 |
| 暴风雪 | 天空饱和、雪粒子密度与速度、树摇幅度 | 20–25 天，25 天归零 |

| 神经透支 | 星闪频率紊乱、呼吸变浅、影子雾 | 理智 < 2 期间 |
| 饥饿 | 地面变暗、雾变黏 | 食物 = 0 期间 |
| 日出 | 天空金粉、星全部消失、地面受光 | 第 40 天，唯一一次跃升 |
| 参数刻度 | 四条竖线高度 / 明暗过渡 / 断口 | 变化时 0.4s 过渡 |

## 7. 文案口径

- 永远第一人称，不出现第三人称旁白
- 陈述而非评价：写"吃得比昨天饱一点"，不写"食物 +4"
- 短句优先，单句不超过一行；句间留白 ≥ 1 秒
- 不解释机制、不使用"提示""教程""目标"等词
- 选项名可自解释（单独猎食 / 集体猎食 / 偷懒打盹 / 舔舐伤口），不加括注
- 事件必须先被看见或听见，再被读到
- 狼群缺席，因此"关系"只能用文字与声音承载：远处嗥叫的有无、风声的疏密、沉默
